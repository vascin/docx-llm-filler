Запуск приложения

Откройте файл editor.html в браузере. Нажмите «Загрузить» в правой панели для загрузки данных из JSON-файла.

Интерфейс

Приложение состоит из двух панелей:

  • Левая панель — DOCX документ с полями для заполнения
  • Правая панель — дерево данных JSON (категории и поля)

Кнопки управления JSON

  • Загрузить — загрузить данные из JSON-файла
  • Сохранить — сохранить текущие данные в JSON-файл

JSON-файл — это библиотека с категориями и полями. По умолчанию файл data.json лежит в папке с приложением. Можно подгрузить обновлённую версию из другого места.

Режим редактирования

Переключатель в правой верхней части панели дерева:

СостояниеЦветДоступно
Выкл (по умолчанию)СерыйТолько перетаскивание в документ
ВклЗелёныйПолное редактирование дерева

Важно: После загрузки страницы редактирование отключено. Для добавления/изменения полей и категорий переключите режим в положение ВКЛ.

Загрузка DOCX шаблона

  • Нажмите кнопку «Загрузить» или используйте Ctrl+O
  • Выберите файл шаблона .docx
  • Документ отобразится в левой панели
  • При наведении ячейка будет подсвечена

Перетаскивание полей в документ

  • Найдите нужное поле в дереве (справа)
  • Зажмите кнопку 📋 рядом с полем и перетащите в нужную ячейку документа
  • Отпустите — значение будет вставлено

Это работает в обоих режимах (Вкл/Выкл).

Добавление/редактирование данных

  • Переключите режим редактирования в положение ВКЛ (зелёный)
  • Добавить категорию: Нажмите «＋ Уровень»
  • Добавить поле: Нажмите «＋ Поле» внутри категории
  • Редактировать название/значение: Кликните на текст и введите новое значение
  • Удалить: Нажмите кнопку ✕ рядом с элементом
  • Переместить: Используйте ручку (⠿) для сортировки

Сохранение документа

  • Нажмите кнопку «Скачать» или используйте Ctrl+S
  • Файл будет скачан в папку загрузок с заполненными данными

Сохранение данных дерева

  • Нажмите кнопку «Сохранить» в правой панели
  • Файл будет скачан в папку загрузок

AI заполнение (Ollama)

Для работы с локальной моделью нужна Ollama с разрешённым CORS:

  • Windows: Установите переменную среды OLLAMA_ORIGINS=* и перезапустите Ollama
  • Linux/Mac: OLLAMA_ORIGINS=* ollama serve
  • Рекомендуемые модели для слабого CPU: gemma3:1b, qwen2.5:1.5b
  • Для Gemini/GigaChat/Yandex введите API ключ в соответствующее поле
