Сопоставь заголовки пустых ячеек с данными организации.

ДАННЫЕ:
{fields}

ПУСТЫЕ ЯЧЕЙКИ:
{doc}

ПРАВИЛА:
- Ключи = ТОЧНЫЕ заголовки из списка ПУСТЫЕ ЯЧЕЙКИ
- Значения = ТОЛЬКО из раздела ДАННЫЕ, копируй точно как есть
- НЕ придумывай данные! Если значения нет в ДАННЫХ — НЕ включай ячейку в ответ
- НЕ возвращай пустые значения ""
- НЕ возвращай ячейки, для которых нет данных
- Телефон → только номер (цифры, скобки, дефисы), НЕ email
- Email → только адрес с @
- Сайт → только URL

Верни ТОЛЬКО JSON, пример формата:
{"ИНН": "1234567890", "Телефон": "8(800)123-45-67"}
