docx-llm-filler

Загрузите Word-шаблон и файл с данными — Gemini заполнит документ и вернёт его обратно. Источник данных: JSON, Word (.docx), Excel (.xlsx), текст (.txt / .md), CSV.

Как это работает

  • Если в шаблоне есть плейсхолдеры вида {{'{{ имя }}'}}, { имя } или [ имя ] — LLM подставит значения на их места.
  • Если плейсхолдеров нет — LLM пройдёт по абзацам и заполнит пустые места, опираясь на JSON как на источник данных.
  • JSON может быть и словарём {"поле": "значение"}, и произвольной базой знаний.
  • Модель: {{ model }}
